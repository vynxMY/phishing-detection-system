Gmail protection

The browser extension shows a short risk summary on Gmail. Full explanation and advice open here on the website. Download the zip, load it unpacked, then paste the API details below.

Download and install

{% if extension_available %}

Package version {{ extension_version }}. Unzip the file — do not load the .zip itself.

Download Chrome / Edge zip
  1. Download and unzip. You should see a folder named phishguard-extension that contains manifest.json.
  2. Open chrome://extensions (Chrome) or edge://extensions (Edge).
  3. Turn on Developer mode (top right), click Load unpacked, and select that folder.
  4. Click the extension’s Details → Extension options (or the puzzle-piece icon → PhishGuard → Settings).
  5. Paste the API base URL and API token from this page, click Save, allow site access if the browser asks, then Test connection.
  6. After you update the site, download a new zip and use Remove then Load unpacked again, or click Reload on the extensions page if you replaced the same folder.

Browsers block websites from installing extensions automatically. The Chrome Web Store listing is a later step; unpacked install is the supported path for this academic prototype.
