About PhishGuard

PhishGuard is an explainable phishing detection system designed to help users identify suspicious URLs and emails.

How detection works

1
Input — you paste a URL or email.
2
Feature extraction — TF-IDF, URL characteristics, and metadata.
3
Machine learning prediction — Logistic Regression.
4
Explainability — the signals that influenced the decision.
5
User recommendation — what you should do next.

Model

Logistic Regression is the single main model.

Features
TF-IDF, URL characteristics, and metadata.
